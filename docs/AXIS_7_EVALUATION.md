# Axis 7 evaluation checklist

- [ ] Define the axis 7 input and output contracts with the rest of the team.
- [ ] Establish a simple baseline before adding model complexity.
- [ ] Use learner-level separation between training and evaluation to prevent leakage.
- [ ] Evaluate calibration as well as ranking or classification accuracy.
- [ ] Document cold-start and sparse-history behavior.
- [ ] Test integration with the shared pipeline on representative learner records.
- [ ] Record dataset provenance, model version, and reproducible metrics.

Do not describe an axis as production-ready until the team has verified its end-to-end integration.
